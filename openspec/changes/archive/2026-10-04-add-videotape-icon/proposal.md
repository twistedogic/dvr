# Proposal

## Why

The PWA's icons are solid-color 192x192 / 512x512 PNGs left over
from the placeholder generation step. They render fine in the
install prompt but communicate nothing about what `dvr` is. A
flat-design videotape icon makes the PWA recognizable as a
single-purpose media player at a glance, both in the install
prompt and on the home screen after install.

## What Changes

- Replace `site/icons/icon-192.png` and `site/icons/icon-512.png`
  with a flat-design videotape illustration: a horizontal
  cassette body, a dark window showing two reels, a white label
  bar, and a red accent stripe.
- The manifest already declares both icons as `any maskable`; no
  manifest change needed. The new PNGs are still opaque, so they
  work under any platform mask.
- The icon is generated by a one-off script (`scripts/make-icon.py`)
  that draws the design with the Python stdlib (`zlib`, `struct`,
  `math`). No new dependencies.

## Capabilities

### New Capabilities

- `dvr-icon`: The visual identity of the PWA. One capability, one
  requirement: the icons exist and are a recognizable videotape.

### Modified Capabilities

None.

## Impact

- Two PNGs replaced. The new ones are larger because the design
  has more pixels (a 192x192 RGBA PNG of a flat design is about
  1-3 KB; previous placeholders were ~400 bytes).
- One new file: `scripts/make-icon.py` (the generator). The
  script is run by hand when the design changes, not at build time.
- `site/manifest.webmanifest` is unchanged: the icon paths and
  `purpose` field already match.
- The PWA install prompt and home-screen icon both pick up the
  new image on the next deploy.
