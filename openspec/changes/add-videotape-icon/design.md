# Design

## Context

The PWA already ships icons at the right paths and sizes; the
add-dvr-pwa change just used solid-color placeholders. This change
replaces those placeholders with a real design. The manifest does
not need to change.

## Goals / Non-Goals

**Goals:**
- A single recognizable subject: a videotape, in flat design.
- No gradients, no shadows, no more than 5 colors.
- Generated by a one-off script the maintainer can re-run by hand
  when the design changes.
- Opaque PNGs that survive a circular mask (the PWA's `purpose`
  is `any maskable`, and iOS Safari applies a rounded mask).

**Non-Goals:**
- No animation, no SVG, no per-platform variants.
- No font rendering, no text inside the icon.
- No new runtime dependency. The generator uses only Python
  stdlib (`zlib`, `struct`, `math`).
- No build-time hook. The script is run by hand, the PNG is
  committed.

## Decisions

### D1. Flat-design cassette, horizontal orientation

**Decision:** A horizontal rectangle (the cassette body) with a
dark window at the top showing two reels, a white label bar at
the bottom, and a small red accent stripe under the label.

**Why:** A horizontal cassette is the most recognizable "videotape"
silhouette. The two reels in a window are the most diagnostic
feature; without them, it could be mistaken for a cassette tape
(audio, not video) or a battery. The label bar and red stripe
(VHS warning label cue) close the recognition loop.

### D2. 5-color palette

**Decision:**
- Background (app dark): `#0a0a0a`
- Body (cassette shell, warm gray): `#b4b2af`
- Window (recessed area): `#282828`
- Reel hub (light): `#dcdcdc`
- Label (white): `#fafafa`
- Accent stripe (VHS red): `#dc3232`

**Why:** Five colors is enough to make the design readable. The
palette is bright on dark: the body and label pop against the
app's `#0a0a0a` background, and the reels and window are dark
enough to read as a recess.

### D3. Generator script: `scripts/make-icon.py`

**Decision:** A small Python script that draws the design
pixel-by-pixel and writes two PNGs (192x192 and 512x512). The
script is run by hand when the design changes; the resulting
PNGs are committed.

**Why:** The runtime is vanilla JS with no build step; adding
a build step just for the icon would be over-engineering. A
hand-run script that produces committed PNGs is the simplest
thing that works. The script is small enough to keep in the
repo for future tweaks.

**Alternatives considered:** Hand-authoring the PNGs in an
image editor (no script, no reproducibility, no easy tweak).
Generating at build time (adds a Python build step to a Node
project for one asset - mismatch).

### D4. Safe area inside a circular mask

**Decision:** The cassette body fills the central 74% of the
canvas (the safe area for a circle inscribed in a square is
about 70% of the square's side). The reels and label live
inside the body. Nothing critical is in the corners.

**Why:** A PWA icon with `purpose: any maskable` may be clipped
to a circle, a squircle, or a rounded rectangle by the host
platform. Keeping the subject inside the inscribed circle
guarantees the icon is recognizable under any of those masks.

## Risks / Trade-offs

- **Generator script is not test-covered.** The script writes a
  binary PNG; the visual outcome is hard to assert in an
  automated test. Verification is by inspection (open the PNG).
  The CI test suite does not run the script.
- **The accent stripe color (`#dc3232`) is bright red.** It is
  the only saturated color in the design. If a future maintainer
  dislikes the VHS-warning-label reference, swap it for `#0a0a0a`
  (a thin dark line) or remove it entirely - the design still
  reads as a tape without it.
- **The design is hard-coded in the script.** Changing the look
  means editing the script and re-running. This is intentional;
  the script is the source of truth.

## Migration Plan

1. Add `scripts/make-icon.py` with the design and PNG writer.
2. Run it; verify the two PNGs.
3. Commit. Push. The CI deploy job publishes the new icons
   unchanged.
4. Reinstall the PWA (or visit the published URL on a phone)
   to see the new icon.

Rollback: `git revert`. The previous solid-color placeholders
are in git history.

## Open Questions

None. The design is small, the script is small, and the
deliverable is two files.
